# Architecture Decision Records

Dieses Verzeichnis enthält die wesentlichen Architekturentscheidungen von OpenBilanz-UG.

Jede ADR dokumentiert:

* den fachlichen oder technischen Kontext,
* die getroffene Entscheidung,
* deren Konsequenzen,
* sowie ihren aktuellen Status.

ADRs werden versioniert und gemeinsam mit dem Quellcode gepflegt.

Sie dienen als langfristige Dokumentation der Architektur und erleichtern die Nachvollziehbarkeit von Entwurfsentscheidungen.
