# ADR-0004: Domain First

## Status

Accepted

## Kontext

Die Software bildet Buchhaltung ab.

Nicht Datenbanken.

Nicht GUI.

Nicht Frameworks.

## Entscheidung

Die Fachdomäne wird zuerst modelliert.

Technische Aspekte folgen erst anschließend.

## Konsequenzen

* Saubere Fachmodelle
* Gute Wartbarkeit
* Unabhängigkeit von GUI und Datenbank
