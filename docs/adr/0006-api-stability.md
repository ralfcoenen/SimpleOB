# ADR-0006: API Stability

## Status

Accepted

## Kontext

OpenBilanz-UG soll langfristig stabil bleiben.

## Entscheidung

Öffentliche APIs werden nur geändert, wenn eine fachliche Notwendigkeit besteht.

Interne Implementierungen dürfen angepasst werden.

## Konsequenzen

* Verlässliche Bibliothek
* Weniger Breaking Changes
* Klare Weiterentwicklung
