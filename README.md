# OpenBilanz-UG

Lokale Buchhaltungs- und E-Bilanz-Software für kleine Kapitalgesellschaften.

## Technologie

- Python 3.12
- PySide6
- SQLAlchemy
- SQLite

## Status

Version 0.13.0

## Ziel

Entwicklung einer modularen Anwendung für:

- Buchführung
- Jahresabschluss
- Bilanz
- GuV
- E-Bilanz/XBRL
